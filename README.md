# 📋 Task Management System

A simple and modern Task Management System built using HTML, CSS, and JavaScript.

## 🚀 Features

* Add new tasks
* Update existing tasks
* Delete tasks
* Mark tasks as completed
* Search tasks
* Filter tasks by status
* Filter tasks by priority
* Task categories
* Set task priority
* Set due dates
* Task counters
* Data stored using Local Storage
* Responsive design
* Purple gradient dark/light interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Font Awesome

## 📂 Project Structure

```text
Task-Management-System/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## ⚙️ How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding and managing your tasks.

## 💡 Task Information

Each task can contain:

* Task title
* Description
* Category
* Priority
* Status
* Due date

## 🔄 Task Status

```text
Pending → In Progress → Completed
```

## 💾 Data Storage

Tasks are stored in the browser using **Local Storage**, so the tasks remain available after refreshing the page.
